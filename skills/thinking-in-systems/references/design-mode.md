# Design Mode (`--design`)

When `--design` is active, all phases shift from analysis to construction. Use this when designing a new system from scratch, wanting to avoid classic failure traps from the start.

## Phase 1 (Design): Define System Structure

Help the user define the system they want to build:

- What stocks should exist, and at what levels?
- What inflows and outflows will govern each stock?
- Which reinforcing loops are desired (growth engines)?
- Which balancing loops are essential (governors, safety valves)?
- Where should delays be minimized? Where is delay acceptable?

## Phase 2 (Design): Proactive Vulnerability Detection

Proactively flag which archetypes the proposed design is structurally vulnerable to, before it's built.

Ask:
- Does this design create a commons (shared, depletable resource)?
- Does it create a success-to-the-successful dynamic?
- Does it offer a symptom-fix escape hatch?
- Are there thresholds where the system could collapse suddenly?

## Phase 3 (Design): Structural and Paradigmatic Levers

Guide toward high-leverage design choices. Note: Points 12–7 (numbers, buffers, material flows, delays, loop gains, loop strengths) are shaped by your stock/flow and loop design choices in Phase 1. Phase 3 focuses on the structural and paradigmatic levers (6–1) that are fixed at design time and hardest to change later.

Key questions:

- **Point 6 — Information flows:** What information should every key actor receive?
- **Point 5 — Rules:** What rules will govern the system? Are they enforceable?
- **Point 3 — System goals:** What is the explicit goal the system will optimize for?
- **Point 4 — Self-organization:** Can the system be designed to learn and evolve its own structure over time?
- **Point 2 — Paradigm:** What paradigm does this system embody, and is that paradigm correct?

## Phase 4 (Design): Design Specification with Resilience

Produce a design spec with explicit resilience mechanisms:

- Named backup feedback loops for each critical balancing function
- Explicit threshold stocks with defined intervention triggers
- Monitoring dashboard specification (what gets measured and by whom)
- Review cadence for reassessing whether the system's actual purpose has drifted from intent

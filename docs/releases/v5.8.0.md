# v5.8.0 — Verified cross-agent skill distribution

This release repairs skill installation, package completeness, deterministic helpers, and verification across Codex, Hermes Agent, Claude Code, Gemini CLI, and Pi.

## Release scope

Published from `feature/hermes-beads-v1`, not `main`. The default branch is deliberately unchanged. The tag includes the branch's existing Beads implementation as well as the installation audit fixes; it is not an audit-only backport onto main.

**Beads advanced-runtime release remains REJECT (`release_eligible=false`).** Packaging verification is not runtime promotion. The original rejection records, frozen evaluator, and frozen design remain unchanged. No model-backed release evaluation was rerun and no default agent profile was promoted.

## Changes

- Exercise all 73 physical packages / 71 unique identifiers through the pinned `skills@1.7.0` installer, with individual project/global copy-mode placement across five agents.
- Bundle missing references, prompts, scripts, templates and review resources inside independently installable skills; validate required assets after installer filtering.
- Enforce package metadata, unique identifier/mirror contracts, hook references and installed package closure.
- Repair browser-profile setup, ADR transitions, property-based examples and package doctor behavior; make unsupported runtime modes fail explicitly.
- Keep the Beads scorer and evidence adapter outside the operational skill. Installed evaluation commands fail closed with `CUSTODIAN_CHECKOUT_REQUIRED`.
- Correct Claude marketplace-registration versus plugin-install instructions, Hermes trust requirements, and agent-specific home/path caveats.
- Provide tested explicit reinstall and narrow quarantine alternatives for upstream installer update/remove defects.
- Add locked verification dependencies, inventory-wide tests, a canonical Makefile gate and tag-triggered CI.
- Include the complete adversarial report and self-contained HTML report with search, severity filters and print support.

## Install this exact release

Because `main` is unchanged, an unpinned repository install does **not** select these fixes. Clone the tag first:

```bash
git clone --branch v5.8.0 --depth 1 https://github.com/citadelgrad/scott-cc.git scott-cc-v5.8.0
npx --yes skills@1.7.0 add ./scott-cc-v5.8.0 --skill acceptance-criteria --agent codex --copy --yes
```

Choose a reviewed skill and one of `codex`, `hermes-agent`, `claude-code`, `gemini-cli`, or `pi`; add `--global` only when that scope is intended. Node 22.20 or later is required. Hermes project discovery additionally needs the real project Git root and explicit trust after review. Custom Pi/Gemini global homes are not supported by this installer pin.

For a Claude development session, load the reviewed tagged checkout with:

```bash
claude --plugin-dir /absolute/path/to/scott-cc-v5.8.0
```

That is session-local, not a persistent marketplace installation. In `/plugin install <plugin>@<marketplace>`, the suffix is a marketplace name, not a Git tag.

## Verification and evidence

The final isolated-release gate results and exact file hashes are in `docs/reports/release-v5.8.0-verification.json`, also attached to the GitHub release. They supersede the earlier working-tree audit receipt for claims about release bytes.

The earlier audit report and HTML retain their historical results: 2,667 full-suite passes with two optional-runtime skips, 1,442 distribution passes with no skips, and 65 independent-review test passes. Those tests included unrelated pre-existing local changes that were deliberately excluded from this release. The release is reverified separately; the historical receipt is not rewritten to pretend otherwise.

Optional probes are not live-runtime certification: the frozen Hermes source and PAS CLI were unavailable. Authenticated browser workflows and universal live-model routing remain unverified. Installer upstream defects remain upstream defects; the documented alternatives do not claim to fix that external project.

Release preparation additionally verifies plugin/marketplace version equality, preserves frozen Beads evidence, runs pre-commit hooks and secret scans, and checks the remote tag and feature-branch commit without moving main.

ai-cli is a useful sensor.
It is not your harness.

Vercel Labs' terminal-native AI SDK has one narrow fit in scott-cc: a pinned, shadow-only semantic classifier for bounded experiments. Its JSON contract is clean. Its judgment is still probabilistic, prompt-injectable, network-bound, and weaker than the controls already built into PAS, Beads, Review Panel, and Hermes evaluation.

?
Conditional pilot only

Pin ai-cli@0.5.1, test it on public or synthetic fixtures, and keep every answer advisory. Do not make it a release gate, PAS dependency, triage authority, research source, or deterministic-evaluator replacement.

The answer in four numbers

The source and published package support a modest conclusion, not a platform rewrite.

The trap: exit code 0 means the evaluation request produced a valid answer. It does not mean the answer was “true,” confident, safe, or above your threshold. False and uncertain answers also exit 0.
Verified fact

A coherent shell contract

Boolean, Choice, and Score questions share one unchanged text or JSON state. Success returns JSON; malformed input, provider failure, timeout, and invalid answers fail without partial JSON.

Inference

A semantic sensor, not an evaluator framework

The caller still owns thresholds, abstention, tie-breaking, batching, evidence, contamination controls, authorization, budgets, and side effects.

Untested hypothesis

Cheap diagnostics may be useful

Jev could add subjective labels or post-validation ordering. No repository-specific live evaluation yet proves better accuracy, calibration, stability, or throughput.

Where it belongs

Keep the existing control plane intact. Put ai-cli beside it as a removable observer, never inside the authority path.

Keep authoritativeDeterministic evidence derivation, hashes, contamination checks, authorization, budgets, review validation, severity, and release decisions.
Allow in shadowA copied, minimized, redacted fixture may receive a Boolean, Choice, or Score annotation. Errors and unavailability remain data.
Never delegateTool authorization, issue acceptance, severity changes, fix dispatch, security decisions, release gates, arithmetic, or exact counting.

Three experiments worth running

No live model call was authorized or needed for this research. These are deliberately small, reversible, and falsifiable.

01

Blinded shadow judge

Question: does Jev add useful semantic diagnostics to Beads evaluation?

  • 40 frozen candidate/control artifacts.
  • At most three atomic questions each.
  • Three repeats; --max-retries 0.
  • Public, synthetic, or redacted data only.
  • Hash state, questions, catalog, package, and output.
Kill it if: it fails the predeclared baseline, flip-rate, injection, latency, or unavailable-output limit—or changes one deterministic score.
02

Post-validation ordering

Question: does a cheap score improve what humans review first?

  • 25 historical validated/rejected findings.
  • One actionability Score and one user-risk Boolean.
  • Blind treatment labels.
  • Include injected code quotes.
  • Never drop an item or cross severity classes.
Kill it if: any Critical is demoted, a rejected item outranks a validated Critical, or repeated ordering is unstable.
03

Operational drift canary

Question: can package pinning plus canaries make drift visible?

  • 12 positive, negative, boundary, and injection fixtures.
  • Verify npm integrity and CLI contract.
  • Assert filter/rank/pick remain absent.
  • Snapshot the evaluation catalog.
  • Inspect response model and provider metadata.
Kill promotion if: model identity is mutable or answer drift breaches the stability bar. Package pinning alone is not model pinning.

Controls before the first paid call

The token price is tiny. The governance surface is not.

Prompt injection

Fact: TypeSafe documents that adversarial state can move Jev answers.

Control: minimize and quote state, use explicit criteria, add injection/negation fixtures, and treat every answer as untrusted advisory data.

Private-data disclosure

Fact: input traverses Vercel AI Gateway to TypeSafe; Gateway retention claims do not govern the upstream provider.

Control: public/synthetic/redacted fixtures only until data classification, DPA, and eligible per-request ZDR are verified.

Model drift

Fact: the executable is pinnable; typesafe-ai/jev and the live catalog are mutable.

Control: log catalog, response model, package integrity, hashes, date, usage, and provider metadata; reapprove on change.

Cost and retries

Fact: evaluate defaults to two retries and a 30-second deadline.

Control: --max-retries 0, short timeout, hard byte/question/call caps, explicit spend ceiling, and no automatic paid fallback.

Artifact leakage

Fact: output may retain provider body, headers, metadata, warnings, and usage.

Control: restricted ephemeral raw output, bounded normalized receipt, stripped bodies/headers, and hashes instead of bulky state.

Runtime availability

Fact: inference is network-bound and authenticated; catalog discovery can warn and return an empty list.

Control: represent auth, timeout, provider, invalid-answer, and unavailable separately. None may silently pass or fail the real gate.

Young API surface

Fact: experimental_evaluate replaced three commands between 0.5.0 and 0.5.1; 0.5.2 followed two days later.

Control: pin package and integrity, isolate behind an adapter, freeze fixtures, and contract-test every upgrade.

Runtime documentation mismatch

Fact: package metadata says Node ≥22; the installation page also mentions Bun. The published bundle ran under Node 22.22.3.

Control: make package metadata and tested artifact authoritative; avoid a global install.

Adoption decision tree

1 · Is the result authoritative?If it can change a release, security decision, issue state, severity, tool call, or deterministic score: reject ai-cli.
2 · Is the input sensitive?If it includes secrets, private source, customer data, or raw transcripts without approved ZDR and contracts: do not send it.
3 · Is the gain measurable?If a frozen, blinded pilot beats a baseline under predeclared quality, stability, latency, injection, and cost bars: keep a narrow optional adapter. Otherwise delete it.
